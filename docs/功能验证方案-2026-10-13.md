## 2. 优先执行的配置交互用例

### C01 单项展开与折叠

- [ ] 默认收起事项，摘要能显示名称与启用状态。
- [ ] 点击一个摘要，只展开该项；再次点击收起。
- [ ] 在名称框修改但不保存，折叠后再展开，输入仍保留。
- [ ] “全部展开”显示八项完整表单，“全部收起”隐藏全部表单。
- [ ] Tab 能聚焦摘要，Enter/空格可切换展开状态；输入框不会触发卡片折叠。

### C02 即时启用与停用

1. 保持概览已打开；展开未启用的事项 5，开启开关，不点击保存。
2. 切回概览及每日记录，检查快捷入口。
3. 重新打开配置或重载插件，确认启用状态保留。
4. 停用事项 5，重复检查。

- [ ] 开启后立即新增对应快捷入口，关闭后立即隐藏。
- [ ] 配置摘要与开关状态一致，重载后状态不丢失。
- [ ] 名称、时长、分数的未保存输入不会随开关被提交。
- [ ] 写入期间开关和保存按钮暂时禁用，结束后恢复可操作。

### C03 当前事项独立保存

1. 修改事项 1 的名称为“阅读验证”，分钟数为 20，分数为 0.8。
2. 把事项 2 名称临时清空，但不保存事项 2。
3. 点击事项 1 内“保存此事项”。
4. 返回看板及重新打开设置核对。

- [ ] 事项 1 保存成功且看板更新。
- [ ] 事项 2 未保存的空名称不会影响事项 1 保存，也不会写入配置。
- [ ] 其他事项和此前即时保存的启用状态保持原值。
- [ ] 页面没有底部统一保存按钮；每项展开后都有独立保存入口。

### C04 输入校验与最低启用数量

- [ ] 保存空名称、负分数、空分数、0 分钟或空分钟数，提示错误且不写入。
- [ ] 0 分是允许值，可成功保存。
- [ ] 只保留一个启用事项后尝试关闭它：提示至少保留一项，开关恢复开启；看板仍保留一个入口。
- [ ] 尝试关闭最后一个事项不会提交该项其他未保存输入。

### C05 1–8 项数量与布局

依次启用 1、2、3、4、5、6、7、8 项，每次检查概览“今日解压”和每日详情的快捷入口。

- [ ] 每种数量下按钮数等于启用事项数，不显示停用项。
- [ ] 按钮按可用宽度换行，没有重叠、内容裁切或固定空白占位。
- [ ] 长名称可换行；调整设置窗口宽度，名称、分钟数、分数标签保持可读。
- [ ] 展开 Obsidian 左右侧栏压缩页面后，主内容可转为纵向排列，明细表可横向滚动。

### C06 自定义记录与停用历史兼容

1. 启用事项 5，设置名称“拉伸验证”、30 分钟、0.5 分并保存。
2. 在一个已结束且有有效考勤的日期新增两次该事项。
3. 停用事项 5，重载插件。

- [ ] 两条记录仍存在，名称仍能识别，累计理论解压为 1 分。
- [ ] 停用只隐藏新增快捷入口，历史记录仍参与当天抵扣。
- [ ] 通过历史记录的编辑入口仍能识别停用事项。
- [ ] 完整明细导出后可重新导入，新增事项类型不被丢弃。

注意：当前名称、时长和分数配置用于重算历史记录；调整这些字段会影响历史展示和计分。启用开关不改变已有记录的计分。

## 3. 三页看板与数据链路

### V01 导航与原型布局

- [ ] 顶部导航可切换概览、每日记录、年度回顾，当前页高亮正确。

- [ ] 每日记录为列表与详情布局；年度回顾为统计卡、月度趋势、分享预览及分布统计。
- [ ] 深色背景、橙色加班、绿色抵扣、粉色最终压力的含义一致。

### V02 考勤导入及重复导入

- [ ] 选择上述原始 JSON，解析预览能读取 `body.list`，显示逐条导入结果。
- [ ] 确认导入后每日列表可定位 2026-10-12，显示上班 09:55、下班缺失和待处理状态。
- [ ] 再次导入，预览提示重复跳过或有明确原因的更新，不创建重复日期。
- [ ] 插件持久化考勤文件不包含姓名、工号和打卡位置。

### V03 概览范围及图表

- [ ] “近30天”“本月”和日期输入能更新指标及趋势。
- [ ] 压力趋势的三条线分别为加班压力、实际抵扣和最终压力，tooltip 值与每日账本一致。
- [ ] 图表页签可切换下班时间、日历热力和压力构成。
- [ ] 点击日历日期或待处理记录进入对应每日详情。
- [ ] 无数据期间不报错；下班时间缺失显示断点，不伪造下班时间。

### V04 每日列表与考勤修正

- [ ] 月份前后切换、月份输入、全部/待处理/人工修正筛选正常。
- [ ] 搜索日期或解压事项名称，结果与搜索条件一致。
- [ ] 点击记录，右侧日期、打卡、工作日、上线日和账本同步变化。
- [ ] 前一天/后一天可进入没有记录的自然日并补录。
- [ ] 对测试日期填写 09:00–22:00 保存，显示人工修正；重载后保持。
- [ ] 时间留空保留缺失；非法时间或下班早于上班应提示错误。
- [ ] 跨夜填写 24:30，展示为次日 00:30，账本按跨夜处理。
- [ ] 查看原始值入口能显示本地保存的脱敏源字段。该入口不是恢复原始值功能。

### V05 解压添加、编辑与删除

- [ ] 概览新增解压归属今天；每日详情新增解压归属选中日期。
- [ ] 编辑日期、事项、次数后列表与详情同步更新，重载后保持。
- [ ] 删除测试记录后累计解压和当天实际抵扣更新。
- [ ] 只有解压、没有考勤的日期仍能在每日记录找到。

### V06 年度回顾

- [ ] 年份选择来自已有数据年份及当前年份；切换后指标、趋势及分享卡同步变化。
- [ ] 三项指标分别为年度加班压力、年度实际抵扣与年度最终压力。
- [ ] 分享预览展示所选年份及真实数值；无网络上传，供本地截图。
- [ ] 晚归分布、解压习惯与对应年度记录一致；空年份正确显示零或空状态。

### V07 明细导出

通过命令“打开考勤数据管理”→“完整明细与导出”进入。

- [ ] 考勤和解压完整明细可查看、编辑、导出。
- [ ] 导出文件存在于当前测试库的“加班时长备份”目录，内容与本地数据一致。
- [ ] 退出/重开插件后数据保持，浏览页面无图表重复或明显卡顿。

## 4. 计分核对样例

仅在已结束的测试日期操作。以下按当前默认压力规则核对：

| 考勤与解压情形 | 预期 |
| --- | --- |
| 工作日下班21:10；散步15分钟，配置0.2分/15分钟 | 加班1分，理论解压0.2分，实际抵扣0.2分，最终0.8分 |
| 工作日下班21:10；骑车60分钟，配置2分/60分钟 | 加班1分，理论解压2分，实际抵扣1分，最终0分 |
| 相邻两日各有1分加班；其中一天记录2分解压 | 合计实际抵扣1分，最终1分，不能跨日结转 |
| 无有效下班时间，但有解压记录 | 显示解压记录，实际抵扣0；最终不当作已结算0分 |
| 今天已有下班时间和解压记录 | 待结算，不提前生成最终压力 |
| 周六/周日有下班时间 | 按现有周末规则计6分；周末跨夜仍优先6分 |
| 非周末跨夜下班24:30 | 加班12分，再按当天解压封顶抵扣 |
